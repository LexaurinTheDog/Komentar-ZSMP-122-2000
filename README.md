# Komentář k zákonu č. 122/2000 Sb., o ochraně sbírek muzejní povahy a o změně některých dalších zákonů

Otevřený komentář k zákonu o ochraně sbírek muzejní povahy — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; centrální evidence sbírek, povinnosti vlastníka sbírky, standardy veřejných služeb, vývoz a přemístění sbírek do zahraničí, zadržení, inventarizace, kontrola a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2000-00122_2025-07-01`.
